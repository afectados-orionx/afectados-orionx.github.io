# afectados-orionx.github.io

Página de entrada para afectados por el cierre de OrionX (3 de septiembre de 2026): qué hacer, dónde denunciar, enlaces al grupo, al monitor de billeteras y a las guías. Sitio estático, sin dependencias ni rastreadores.

- `index.html`: la página. Los enlaces principales están al inicio, en el bloque `<nav class="botones">`.
- `GUIA_pasos_afectados_OrionX.pdf`, `PLAN_accion_afectados_OrionX_grupo.pdf`: documentos del grupo.
- `robots.txt`, `sitemap.xml`: para los buscadores.
